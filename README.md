# Food Ordering System

A responsive food ordering website developed using HTML and CSS. The project provides a modern user interface for browsing food items, exploring menus, viewing offers, and placing food orders.

---

## 📌 Project Overview

This project is a frontend food ordering website designed to provide users with a clean and attractive interface for ordering food online.

The website includes multiple sections such as:

- Hero Banner
- Why Choose Us
- Explore Menu
- Delivery & Payment
- Gift Voucher
- Follow Us

---
## 🚀 Features

- Responsive Design
- Attractive Landing Page
- Food Menu Section
- Delivery & Payment Information
- Gift Voucher Popup
- Social Media Section
